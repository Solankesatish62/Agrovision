# Change Log

All notable changes to the AgroVision project will be documented in this file.

---

## [MVP Status] - Current
The project is currently in the MVP (Minimum Viable Product) stage. The core infrastructure is functional and deployed for testing.

### Added
*   **Recognition Engine:** YOLO object detection and ML Kit OCR integration.
*   **Android Kiosk App:** Core UI, CameraX integration, and `ResultActivity`.
*   **Localization:** Marathi audio narration and text display.
*   **Cloud Infrastructure:** Firebase Firestore, Storage, and Authentication setup.
*   **Admin Dashboard:** React-based management tool for medicines and shop monitoring.
*   **OTA System:** Initial Over-the-Air update capability.
*   **Ad Engine:** Advertisement mode for idle kiosk states.
*   **Scan Logging:** `daily_scans` tracking in Firestore.

### Current Focus
*   Performance optimization of the recognition pipeline.
*   Improving recognition accuracy under varying lighting conditions.
*   Integration of barcode scanning.
*   Expansion of the `approved_medicines` database.
*   Automating the data acquisition process.
