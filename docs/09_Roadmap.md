# Project Roadmap

This document outlines the development trajectory of the AgroVision project, categorized by immediate development goals and long-term strategic vision.

---

## 1. Current Development Phase (In-Progress)

### 1.1 Recognition Enhancements
*   **Barcode Scanner Integration:** Adding support for barcode scanning to serve as a high-confidence primary or secondary identification method.
*   **Barcode-first Recognition:** Transitioning the pipeline to prioritize barcode data when available.
*   **Performance Optimization:** Specifically targeting recognition speed and accuracy improvements.

### 1.2 Data & Storage Tools
*   **Storage Browser:** Implementing a better way to manage and browse media files within the system.
*   **AI-assisted Medicine Entry:** Developing tools to help administrators enter new medicine data faster.
*   **Automatic Image Downloader:** Automating the retrieval of high-quality product images.
*   **Automatic Information Collection:** Building scrapers or integration tools to gather medicine data from verified sources.

---

## 2. Mid-Term Goals (Next 6-12 Months)

### 2.1 Ecosystem Expansion
*   **Analytics Engine:** Providing deeper insights into scan trends, popular products, and regional disease outbreaks.
*   **Company Dashboard:** A dedicated interface for medicine companies to monitor their product performance and ad reach.
*   **Distributor Dashboard:** Tools for distributors to see regional demand.
*   **Survey Platform:** Using the kiosk as a tool for conducting farmer surveys.

### 2.2 Functional Upgrades
*   **Voice Assistant:** Integrating a Marathi voice assistant to allow farmers to ask questions naturally.
*   **Inventory Integration:** Connecting the kiosk to the shop's local inventory system to show real-time availability and pricing.

---

## 3. Long-Term Vision (Future OS)

### 3.1 Total Retail Integration
*   **Farmer Mobile App:** A companion application for farmers to access their scan history and receive personalized advice.
*   **AI Data Acquisition:** Fully automating the process of identifying and cataloging every agriculture medicine in the market.
*   **Marketplace:** Facilitating direct connections between farmers and products.
*   **The OS for Agri-Retail:** Transforming AgroVision into the standard operating system that runs all technological aspects of an agriculture input shop.

---

## 4. Development Philosophy for Roadmap Items
*   **Trust First:** Every new feature must undergo rigorous testing to ensure it doesn't compromise the "Zero Tolerance for Incorrect Medicine" rule.
*   **Modular Growth:** New components should be developed as independent modules that integrate into the existing architecture without requiring a redesign.
*   **Human-Centric AI:** Future AI features (like the Voice Assistant) will remain assistive, with human oversight remaining the gold standard for data verification.
